EXPLICAÇÃO DO CÓDIGO — O QUE É AUTOMÁTICO E O QUE NÃO É
==========================================================

==========================================================
VISÃO GERAL DO SISTEMA
==========================================================

O sistema tem duas partes que trabalham juntas:

  1. APPS SCRIPT (apps-script/Code.gs)
     Roda dentro do Google — lê as pastas e planilhas do Drive e
     entrega os dados como uma API (endereço de internet).

  2. DASHBOARD (dashboard/)
     Página web que consome essa API e exibe gráficos, filtros e
     tabelas para o usuário final.

==========================================================
O QUE O APPS SCRIPT FAZ AUTOMATICAMENTE
==========================================================

O script é acionado sempre que alguém abre o dashboard ou clica
em "Atualizar dados". Nesse momento ele:

  ✔ Abre a pasta "mackenzie" no Drive
  ✔ Lista todas as subpastas (= cursos)
  ✔ Para cada curso, lista as subpastas (= semestres)
  ✔ Dentro de cada semestre, encontra o arquivo cujo nome começa
    com "AVALIAÇÃO DISCENTE" (não importa o resto do nome)
  ✔ Lê todas as linhas e colunas dessa planilha
  ✔ Detecta automaticamente quais colunas são notas (valores de 1 a 10)
  ✔ Monta um JSON com todos os dados e entrega para o dashboard
  ✔ Ordena os semestres por nome (2026.1 < 2026.2 < 2027.1 etc.)

Resultado: qualquer pasta ou planilha que já exista no Drive no
formato correto será lida e exibida automaticamente, sem nenhuma
mudança no código.

==========================================================
O QUE O APPS SCRIPT NÃO FAZ — RESPOSTAS DIRETAS ÀS SUAS PERGUNTAS
==========================================================

PERGUNTA: Se eu criar uma nova pasta de curso dentro de "mackenzie",
o script consegue abastecer essa pasta com um formulário e gerar
a planilha automaticamente?

RESPOSTA: NÃO.

O script é somente de LEITURA. Ele não cria pastas, não cria
formulários, não gera planilhas. Ele apenas lê o que já existe.

Se você criar a pasta "mackenzie/Engenharia de Software/", o script
vai reconhecer o curso automaticamente — mas a pasta precisa já ter
pelo menos uma subpasta de semestre com uma planilha dentro para
que apareça dados no dashboard.

---

PERGUNTA: Quando começar o semestre 2026.2, o código cria sozinho
a pasta "2026.2" e atualiza o formulário?

RESPOSTA: NÃO.

O código não cria pastas. Alguém (um administrador) precisa:
  1. Criar manualmente a pasta "2026.2" dentro do curso no Drive
  2. Colocar a planilha de respostas dentro dessa pasta
     (com nome começando em "AVALIAÇÃO DISCENTE")

Feito isso, na próxima vez que o dashboard for atualizado, o
semestre "2026.2" aparece automaticamente no seletor — sem
precisar mudar uma linha de código.

---

PERGUNTA: O sistema é autossuficiente para criar novos formulários?

RESPOSTA: NÃO.

O Google Forms (formulário de coleta de respostas) é completamente
separado do sistema. O sistema apenas lê a planilha que o Forms gera.
O fluxo correto é:

  Passo humano 1: Criar o Google Forms para o novo semestre
  Passo humano 2: Configurar o Forms para salvar respostas em uma
                  planilha dentro da pasta correta no Drive
  Passo humano 3: Garantir que o nome da planilha comece com
                  "AVALIAÇÃO DISCENTE"

  Automático: o dashboard lê e exibe os dados dessa planilha

==========================================================
RESUMO — O QUE É MANUAL VS AUTOMÁTICO
==========================================================

MANUAL (feito por um humano, uma vez por semestre):
  - Criar a pasta do semestre no Drive (ex: "2026.2")
  - Criar o Google Forms para coleta de notas
  - Vincular o Forms a uma planilha dentro da pasta do semestre
  - Garantir que o nome da planilha comece com "AVALIAÇÃO DISCENTE"

AUTOMÁTICO (o sistema faz sozinho):
  - Ler e exibir todos os cursos e semestres que existirem no Drive
  - Detectar quais colunas da planilha são notas (1 a 10)
  - Calcular médias, rankings, comparativos entre semestres
  - Atualizar os seletores de filtro (curso, semestre, turma, mês)
  - Exibir gráficos (radar, barras, linha, histograma, comparativo)
  - Exportar relatório em PDF e XLSX
  - Detectar novos cursos ou semestres sem alterar o código

==========================================================
POR QUE O SISTEMA FOI PROJETADO ASSIM?
==========================================================

O Apps Script poderia ser programado para criar pastas e formulários
automaticamente, mas isso exigiria:

  - Permissões muito amplas no Google Drive da instituição
  - Uma lógica de "quando criar" (gatilhos de datas, regras de negócio)
  - Manutenção mais complexa se algo der errado

A opção de LEITURA APENAS foi escolhida porque:
  - É mais segura (o script não pode apagar ou modificar nada)
  - É mais simples de auditar e corrigir
  - A criação do formulário e da pasta já é feita naturalmente pelo
    processo pedagógico do semestre de qualquer forma

==========================================================
FLUXO COMPLETO DE UM NOVO SEMESTRE — PASSO A PASSO
==========================================================

  1. [HUMANO] Cria pasta "2026.2" dentro de "mackenzie/Ciência de dados/"
  2. [HUMANO] Cria Google Forms com as perguntas de avaliação
  3. [HUMANO] Configura Forms para salvar em planilha chamada
             "AVALIAÇÃO DISCENTE - Ciência de dados - 2026.2"
             dentro da pasta "2026.2"
  4. [HUMANO] Distribui o link do Forms para os alunos
  5. [ALUNOS] Respondem o formulário ao longo do semestre
  6. [AUTOMÁTICO] Dashboard lê a planilha e exibe os dados em tempo real
  7. [AUTOMÁTICO] Quando há mais de um semestre, o comparativo entre
                  semestres é gerado automaticamente

==========================================================
DETECÇÃO AUTOMÁTICA DE COLUNAS DE NOTA
==========================================================

Um detalhe importante: o dashboard não sabe de antemão quais colunas
da planilha são notas. Ele detecta automaticamente qualquer coluna
cujos valores sejam todos números entre 1 e 10.

Isso significa que se no futuro forem adicionadas novas perguntas ao
formulário (novos critérios de avaliação), elas aparecerão
automaticamente nos gráficos sem nenhuma alteração no código.

Colunas que não são notas (nome, e-mail, turma, data) são usadas
para filtros e identificação, mas nunca exibidas publicamente.
